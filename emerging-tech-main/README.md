# emerging-tech
This is a repository for my CPE3205 course emerging technology where we have to research about the CIFAR-100. For this activity, we chose food containers as our superclass, and bottles, bowls, cans, cups, plates as our classes.

These are the instructions for this activity:
1. python install on vscode

      -enable path

    pip --version

    Open cmd terminal on project folder
        Ctrl + ~
4. Run:
